# 예시 데이터 (치킨집 · 카페 · 중국집)

세 가지 업종의 매장을 **화면에서 직접 입력해 보기 위한** 예시 데이터다. 재료 단가, 레시피 양, 판매가, 인건비, 배달앱 수수료는 **2026년 공개 자료**에서 찾은 값을 썼다. 자료를 찾지 못한 값은 표에 **(가정)**이라고 표시했다. 실제 매장마다 크게 다르므로 "그럴듯한 출발점"으로만 쓴다.

## 직접 입력하는 순서

매장 하나를 고른 뒤(아래 1~3장) 이 순서대로 넣는다. 한 매장을 끝까지 넣어 본 다음 다른 매장은 **다른 이메일로 새로 가입**해서 넣는다.

| 순서 | 화면 | 넣을 것 | 넣고 나면 보이는 것 |
|------|------|---------|--------------------|
| 1 | 로그인 → 가입 | 아래 계정표의 이메일·비밀번호·매장명 | 빈 대시보드 |
| 2 | 식재료 | 매장별 **식재료** 표 (이름, 양, 단위, 가격, 수율 %). kg·L로 넣어도 된다: 치킨 파우더 → `5` `kg` `1.5만`. 마지막 칸에서 Enter | 1g·1ml·1개당 단가, 수율이 100%가 아니면 "손질 후" 단가 |
| 3 | 메뉴와 레시피 | 매장별 **메뉴와 레시피** 표: 메뉴명·판매가 → "추가하고 레시피 넣기" → 재료 고르고 양 입력 → 레시피 저장 | 메뉴별 재료비 (남는 돈은 4단계 채널을 넣은 뒤) |
| 4 | 판매량 → 채널 버튼 | "+ 홀", "+ 배민", "+ 쿠팡이츠" | 판매 채널 생성. "판매 채널과 수수료"를 펼쳐 아래 공통 근거의 수수료로 맞춤 |
| 5 | 판매량 → 새 달 | 2026-10 추가 → 표에 10월 판매량, **주문 건수** 줄에 배민·쿠팡이츠 주문 수 → 저장 | 메뉴·채널별 합계 |
| 6 | 고정비 | 매장별 **고정비** | 월 합계 |
| 7 | 매입 | 판매 기간 **2026년 10월** 선택 → 매장별 **10월 매입** 표를 **한 줄씩 전부** (날짜, 금액, 거래처 → Enter) | 매입 합계, 레시피 원가 vs 실제 매입 차이, "이것만 세면 됩니다" |
| 8 | 이익 | 확인만 | 실제 남는 돈, 손익분기 매출, 채널별 마진, 메뉴별 기여도 |
| 9 | 이상징후 | 식재료 화면 목록에서 **이상징후 데모** 재료의 가격 칸을 새 가격으로 고치고 Enter | 이상징후 화면에 "식재료 가격 상승: ○○ … 후라이드치킨 +167원" 알림이 바로 생김 |

> **레시피는 3번 메뉴 단계에서 같이 넣는다.** 메뉴를 추가하면 바로 레시피 편집이 열린다. 매장별 **메뉴와 레시피** 표대로 재료를 고르고 양(g·ml·개)을 넣는다. 레시피가 없으면 원가, 남는 돈, 매입 vs 이론 원가 비교, 원가 상승 알림이 계산되지 않는다.

| 매장 | 이메일 | 비밀번호 | 매장명 |
|------|--------|----------|--------|
| 바삭치킨 | `chicken@example.test` | `demo-pass-1234` | 바삭치킨 |
| 온기커피 | `cafe@example.test` | `demo-pass-1234` | 온기커피 |
| 홍반점 | `chinese@example.test` | `demo-pass-1234` | 홍반점 |

입력 없이 결과만 빨리 보고 싶을 때는 같은 데이터를 스크립트로 넣을 수 있다: `node scripts/seed-demo.mjs http://localhost:3000` (지우기만: `--clean`, 지우고 다시: `--reset`). 위 계정과 같은 이메일을 쓰므로, 직접 입력한 계정이 있으면 건너뛴다.

## 다 넣었을 때 나와야 하는 값 (레시피까지 입력, 2026년 10월)

직접 입력한 결과와 비교용. **판매량과 매입은 반드시 "2026년 10월"로** 넣어야 이 값이 나온다. 고정비는 한 달 전체면 월 금액 그대로 빠진다.

**9단계(가격 인상) 전**

**값이 다를 때 자주 하는 실수**

- 판매량을 11월에 넣음 → 판매량 화면 "기간"에서 10월인지 확인 (새 달은 기본이 지난달)
- 매입을 일부 빠뜨림 → 매입 화면의 "이 기간 매입 N건 · 합계"가 위 표의 건수·합계와 같은지 확인
- 수율·단위 실수 (g인데 kg으로, 또는 반대) → 식재료 목록의 "1g당 ○원"이 표의 단가와 같은지 확인

채널별로 보면 같은 메뉴라도 배달앱 마진율이 홀보다 크게 낮다. 예를 들어 치킨집은 홀 54%, 배민·쿠팡이츠 33%다.

## 알아둘 점

- 레시피 원가는 **현재 단가 기준**이다. 9단계에서 단가를 올리면 10월 레시피 원가도 올라간 단가로 다시 계산된다.
- 배달앱 메뉴 가격을 홀보다 비싸게 받는 매장이 많지만, 채널별 판매가 입력 화면이 아직 없어 같은 가격으로 넣었다.
